# Checkpoints / Gespeicherte Trainingsstände (Brains)

In diesem Ordner werden die gespeicherten neuronalen Netze und Populations-Zustände (.json) abgelegt.

## Dateien:
- `mario_brain_gen16.json`: Trainingsstand nach 16 Generationen (Level 1-1, 13 Eingaben -> 12 Hidden -> 7 Aktionen).

## Verwendung im Dashboard:
- Klicke im Dashboard auf **Laden** und wähle die gewünschte `.json`-Datei aus diesem Ordner aus.
- Klicke auf **Speichern**, um den aktuellen Trainingsstand hier zu sichern.
